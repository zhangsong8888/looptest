# 计算器 Calculator

一个零依赖的网页计算器：打开 `index.html` 即可使用。支持键盘输入、运算优先级、百分号、历史记录和深色模式。

## 功能

- 四则运算，按先乘除后加减的顺序计算，同级运算左结合
- 百分号按常见计算器语义处理：`200 + 10% = 220`、`200 × 10% = 20`
- 浮点结果自动收敛（`0.1 + 0.2` 显示 `0.3`），最多保留 12 位有效数字
- 除以 0、结果溢出等异常会给出中文提示，而不是显示 `Infinity` / `NaN`
- 支持键盘：数字、`+` `-` `*` `/`、`%`、`.`、`Enter` 计算、`Backspace` 退格、`Esc` 清空
- 最近 20 条计算记录保存在 `localStorage`，点击记录可复用结果
- 深色 / 浅色主题切换，默认跟随系统
- 响应式布局，窄屏下历史记录移到计算器下方

## 运行

直接双击 `index.html` 即可；也可以起一个本地静态服务（推荐，`localStorage` 和模块行为更一致）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或者：

```bash
npm start
```

## 测试

计算逻辑抽离在 `calculator.js`，不依赖 DOM，使用 Node 内置测试运行器验证：

```bash
npm install   # 仅测试需要 jsdom
npm test
```

## 设计说明

- 输入状态由 `tokens`（已确定的数字与运算符）+ `entry`（正在输入的数字）组成，操作符可连续替换，避免出现非法表达式。
- 百分号在运算时结合左侧上下文解析：加减法按左值取百分比，乘除法按数值除以 100。
- 计算过程不使用 `eval`，全部在 `calculator.js` 中显式解析。
